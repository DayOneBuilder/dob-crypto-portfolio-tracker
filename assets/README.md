# Crypto Portfolio Tracker Starter

This bundle is the first sellable draft asset for the DayOneBuilder crypto tracker product.

## Included file

- `crypto-portfolio-tracker-starter.xml` — multi-tab spreadsheet template that opens in Excel / LibreOffice / Numbers-compatible apps

## Tabs

- `Instructions` — setup notes and event-type guidance
- `Wallets` — one row per wallet or exchange account
- `Transactions` — ledger for buys, sells, transfers, bridges, staking, rewards, airdrops, LP events, and fees
- `Holdings` — current balances, prices, current value, cost basis, unrealized P&L
- `Dashboard` — starter totals for portfolio value, cost basis, unrealized P&L, realized P&L, fees, and wallet count
